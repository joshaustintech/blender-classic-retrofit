# Preserve Blender-owned UI while using current macOS chrome

Every Blender-owned screen, control, font, icon, dialog, shortcut, default, and logical-pixel layout must retain the reference behavior. Current macOS window frames and Dock appearance are allowed instead of recreating period macOS chrome. This keeps the preservation boundary at the application while allowing a native macOS host; screenshot comparisons separate application content from OS decorations, and window behavior still requires verification.
